# Prompt for your AI assistant

> Inspect the AlienApe repository and relevant tests first. Preserve its controller architecture, permissions, WriteScope, redaction and verification boundaries. Classify failures by cause before proposing changes. Treat new features as hypotheses and prefer a small measurable experiment over speculative rewrites. Add regression tests for real bugs; never weaken tests merely to make them pass. Explain what changed, what was tested, and what remains untested.
